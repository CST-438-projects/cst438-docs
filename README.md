# CST 438 Software Engineering: course documents

Student-facing documents for CST 438 at CSU Monterey Bay. Project prompts and rubrics live here so
they are versioned and always available. **Dates live in Canvas**, not in these files.

| Project | Prompt |
|---|---|
| Project 1 | [projects/p1](projects/p1/README.md) |
| Project 2: Build a REST API | [projects/p2](projects/p2/README.md) |
| Project 3 | [projects/p3](projects/p3/README.md) |

Starter repos for each project are the `CST438_*` template repos in this org. Use **Use this template**
on those; this repo is documentation only.

Each term is tagged (`fa26`, `sp27`, ...) so an older version of a prompt stays available.
