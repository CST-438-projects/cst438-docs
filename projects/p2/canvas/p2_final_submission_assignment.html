Goal

Turn in the project itself. This assignment grades what you built and shipped: the repository, the deployed API, the tests, the container, the Android client and the documentation. It is graded from your repo and from URLs anyone can open.

Your presentation is graded separately, on the Project 2: Presentation assignment. No part of this grade comes from watching a video.

What you submit

A PDF containing:

  • A link to the API repository and to the Android repository
  • The live API URL, and the Swagger URL on that deployment
  • A link to the GitHub release carrying your Android debug APK
  • A link to the most recent green CI run on your default branch

Everything else is graded from what is in those repositories. Make sure your default branch is the branch you want graded: work sitting on an unmerged feature branch does not count.

What we check

The deliverables described in the Project 02 prompt:

  • The hand written openapi.yaml and the other design artifacts in /docs
  • The deployed API and its Swagger docs
  • The test suite, its coverage gate, and CI green on the default branch
  • Docker: the multi stage build, the compose file, and the image built by CI
  • detekt, with a committed ruleset, failing the build on violations
  • The Android client, delivered as an APK release plus committed screenshots
  • The README in each repo

Your agile process is already graded by the iteration PR reports and the retrospectives, so it is not re-graded here.
